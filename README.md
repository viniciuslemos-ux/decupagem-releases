# Decupagem: instaladores

Instaladores do app Decupagem, da Prota Games, para uso da equipe.

Baixe o `Decupagem-Setup-X.Y.Z.exe` da versão mais nova em [Releases](https://github.com/viniciuslemos-ux/decupagem-releases/releases/latest).
Na primeira instalação o Windows mostra "O Windows protegeu o computador": clique em "Mais informações" e depois em "Executar assim mesmo".
Depois disso o app se atualiza sozinho.
